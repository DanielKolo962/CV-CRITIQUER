# CV-CRITIQUER

AI-powered resume analysis and optimization tool built with Python, Streamlit, LangChain, and Groq.

CV-CRITIQUER analyzes a resume and provides:

- Resume scores
- ATS compatibility analysis
- Critical issues
- Strengths
- Recommended changes
- Missing keywords
- Skills analysis
- Suggested professional summary

## Prerequisites

Before installing CV-CRITIQUER, make sure you have:

- Python 3.12 or newer
- Git
- `uv` package manager
- A Groq API key

### Install uv

If `uv` is not already installed, follow the official installation instructions:

https://docs.astral.sh/uv/getting-started/installation/
